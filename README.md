## ┌─── 🚀 Installation & Setup

### Step 1 — Install a Local Web Server

Download and install one of the following:

```
🔗  XAMPP  →  https://www.apachefriends.org/
🔗  WAMP   →  https://www.wampserver.com/
```

> XAMPP is recommended — it bundles Apache, MySQL, and PHP in one click.

### Step 2 — Clone the Repository

```bash
git clone https://github.com/laraib776/IU-Music-Hub-E-commerce-Store.git
```

### Step 3 — Move to Server Directory

```bash
# For XAMPP — place the project folder inside:
/xampp/htdocs/IU-Music-Hub/

# For WAMP — place it inside:
/wamp/www/IU-Music-Hub/
```

### Step 4 — Set Up the Database

```
1. Open phpMyAdmin  →  http://localhost/phpmyadmin
2. Create a new database  (e.g.  iu_music_hub)
3. Import the provided  .sql  file into the database
4. Update  db_config.php  with your database credentials
```

### Step 5 — Launch the Website

```
🌐  Open your browser and visit:
    http://localhost/IU-Music-Hub/index.php
```
